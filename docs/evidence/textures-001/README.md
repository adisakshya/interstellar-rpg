# TEXTURES-001 evidence: real surfaces

The props and rooms were flat-coloured boxes. Three CC0 Poly Haven material sets (1K colour and normal maps, converted to
WebP; 280 KB in all, against the 6 MB Miller and 3 MB Endurance budgets) now cover them:

- `rusty_metal_02`: the wreck of Miller's lander.
- `metal_plate_02`: the Ranger's hull, the wreck's plating, Endurance's walls and ceiling.
- `concrete_floor_worn_001`: Endurance's floor.

Every file is in `docs/ASSETS.md` with its source, author and licence, and a test requires that every file in `public/` is
credited (so the credits screen lists them). The material colour still multiplies each map, so the dust that builds up on
Endurance's walls over the years keeps working on top of the texture.

`miller.png`, `endurance-0.5y.png`, `endurance-25y.png`.
