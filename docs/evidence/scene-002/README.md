# SCENE-002 evidence: Miller's plain dressed

Everything is built in code (D-17): no new files in `public/`, nothing to add to the asset ledger.

- **Haze:** exponential-squared fog (density 0.011, cold dark teal) on every exterior object; the sky, the wave and the
  beacon's lamp ignore it, so the horizon sinks into the dark and the lamp stays visible through it.
- **Water:** a scrolling normal map made in code (no image, no canvas) and a warm tight specular, so Gargantua's light
  glints on the swell toward the viewer; the seabed shows through on `high`.
- **Props:** the Ranger on its legs (right of the start, window glowing amber), the beacon on a mast with a slowly
  pulsing amber lamp (ahead, on the horizon), the half-sunk wreck of Miller's lander with a standing wing-plate (left,
  far). Warm rim light from the disk, cold fill from the sky.
- **Feet:** a pale ripple ring around each wading figure that spreads faster the faster they wade.
